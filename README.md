## 💼 2. Personal Wealth & AI Financial Operating System (`Personal Wallet`)

A 100% dynamic, MongoDB-backed 9-subtab executive financial operating system:

### 📊 Key Wallet Subtabs & Features

1. **📊 Single Month Ledger & 31-Day Heatmap Matrix:**
   - Real-time tracking of Salary, Freelance Revenues, Addons, Bonuses, and Expenses.
   - Interactive 31-Day expenditure timeline with no-spend streak indicators and peak outlay highlights.

2. **🌐 Global Summary & Lifetime Capital Ledger:**
   - Multi-month performance ledger table with gross inflows, outflows, savings margins, and health status badges.
   - Global Portfolio Capital Allocation & Asset Reserve HUD (`Liquid Savings + Asset Valuation - Active Liabilities`).

3. **📈 Smart Analytics & 4-Week Monthly Phase Breakdown:**
   - Dynamic 4-week phase breakdown (Week 1: Days 1–7, Week 2: Days 8–14, Week 3: Days 15–21, Week 4: Days 22–31).
   - Peak spending velocity detector and Peak Single Spending Date HUD (`exact date, amount, and top item`).

4. **🏦 Wealth Vault & Net Worth Asset Coverage Radar:**
   - Live asset management (Bank Deposits, Equities, Workstation Gear) with automated growth rate tracking and asset-to-liability coverage ratios.

5. **🤖 AI Executive Copilot & Monte Carlo Risk Forecast:**
   - **Monte Carlo 3-Tier Risk Forecast**: 1,000-iteration statistical simulation projecting Optimistic (-20% spend), Expected (current pace), and Conservative (+25% spend) month-end cash.
   - **FIRE Freedom Roadmap Timeline**: Calculates Financial Independence (FIRE) target numbers and zero-income living runway months.

6. **🎯 Category Budget Limits & Over-Spending Warnings:**
   - Strict 8 core sector budget caps (`Food`, `Rent`, `Utility`, `Gadgets`, `Server`, `Entertainment`, `Parents`, `Other`).
   - Unlisted custom expenses automatically map into the `Utility` sector cap, maintaining strict budget boundaries.

7. **📅 1st-of-Month Auto-Month Creation Engine:**
   - Automatically provisions missing month sheets on the 1st of every month (e.g. `August 2026`).
   - Auto-detects total days in month and carries over remaining net cash into `carriedOverSavings`.

8. **🔔 Staggered 5-Slot Automated Dispatch & QuickChart Infographics:**
   - **Staggered Schedules (BST)**:
     - 🌅 **9:00 AM BST**: Morning Kickoff & Daily Spending Cap Allowance.
     - 🕒 **3:00 PM BST**: Mid-Day Pace & Category Over-Spending Alerts.
     - 🕕 **6:00 PM BST**: Wealth Vault Net Worth & Active Debt Recovery Reminders.
     - 🕘 **9:00 PM BST**: AI Executive Copilot, Monte Carlo Risk & Lifestyle Guidance.
     - 🕛 **11:30 PM BST**: Day-End Closing Audit & Smart Analytics Infographics.
   - **QuickChart Image Generation**: Automatically renders PNG chart infographics for Telegram dispatches alongside HTML monospace `<pre>` table summaries.

9. **🔔 Dispatch Command Center Tab:**
   - Dedicated interactive testing hub to preview, trigger, and audit all 5 daily slots, month-end closing dispatches, and weekly reports with 1-click test buttons.

## 🚀 Environment & Deployment Setup

### 1. Configure Environment Variables (`.env.local`)
Create `.env.local` in the root directory:

```env
# MongoDB Connection String
MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/portfolio?retryWrites=true&w=majority

# Security & Authentication
JWT_SECRET=your_jwt_secret_key
ADMIN_EMAIL=your_admin_email@gmail.com
ADMIN_PASSWORD=your_secure_admin_password

# Multi-Channel Push Notifications (Telegram & Email)
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=your_telegram_chat_id
GMAIL_USER=your_gmail_sender@gmail.com
GMAIL_APP_PASSWORD=your_gmail_app_password
```

### 2. Install Dependencies & Launch
```bash
# Install package dependencies
npm install

# Run local development server
npm run dev
```

Visit `http://localhost:3000` for the main portfolio, or `http://localhost:3000/admin` for the Executive Admin Portal & Financial OS.
